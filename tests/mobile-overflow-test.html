Regression test: mobile overflow (375px) with a long unit label

Bug found during QA (2026-09-11): a long "Quantity / unit label" value makes the item card wider than the 375px viewport. .item-original uses white-space: nowrap and its parent .item-card-price uses flex-shrink: 0, so the price/unit line is never allowed to wrap or shrink — it pushes the card (and the Edit/Remove buttons) off-screen instead of wrapping. overflow-x: hidden on html, body only hides the resulting scrollbar; it does not stop the content from being clipped and unreadable.

Open this file through the same web server as the app (e.g. http://localhost/workplaces/price-compare/tests/mobile-overflow-test.html) so the iframe below can load ../index.php same-origin.
